# label-generator/ — сервис генерации этикеток

> Здесь будет отдельный сервис для генерации этикеток с QR-кодами
> для тары, проб и ячеек. Цель — Уровень 2 интеграции с
> лабораториями.

## Что здесь

- REST API для генерации PDF с этикетками.
- Шаблоны этикеток (тара, проба, ячейка).
- Генерация QR-кодов с полезной нагрузкой (ID + контекст).
- Возможность использования лабораториями напрямую.

## Стек (предварительно)

- Python (FastAPI или Django)
- `qrcode` — генерация QR
- `reportlab` / `weasyprint` — PDF
- Jinja2 — шаблоны

## Зачем отдельный сервис

- Лаборатории могут печатать этикетки через API, не имея доступа
  ко всей WMS.
- Легче масштабировать и обновлять независимо от основной системы.
