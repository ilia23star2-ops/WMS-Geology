# mobile/ — Flutter-приложение для Android-планшетов

> Здесь будет мобильное приложение для кладовщиков и менеджеров.

## Что здесь

- Flutter-проект для Android (планшеты).
- Сканер QR-кодов (камера).
- Поиск проб по номеру, Н/З, типу исследования, участку.
- Инвентаризация (сессии, сканирование, синхронизация).
- Приёмка, перемещение, выдача.
- Наряд-задания в виде списка задач.
- Офлайн-режим (SQLite-кэш).

## Стек

- Dart / Flutter 3.x
- Material 3 (UI)
- `mobile_scanner` — сканирование QR
- `google_ml_kit` — OCR для старых этикеток
- `sqflite` — локальный кэш
- `dio` / `http` — HTTP-клиент
- `provider` / `riverpod` — управление состоянием (решим в серии 1.2)

## Целевые устройства

- Android-планшеты (основное).
- Возможен запуск на Android-смартфонах (не приоритет).
