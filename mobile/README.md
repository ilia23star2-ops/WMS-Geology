# mobile/ — Flutter-приложение для Android-планшетов

> Мобильный клиент WMS Geology для кладовщиков и менеджеров.

## Что здесь

- Flutter-проект для Android.
- Сканер QR-кодов (камера планшета).
- Поиск проб по номеру, Н/З, типу исследования.
- Инвентаризация: сессии, сканирование, расхождения.
- Приёмка, формирование поддона, перемещение.
- Виртуальный вид секции (A–D × 1–3).
- Наряд-задания в виде списка задач.
- Офлайн-режим (SQLite) — в следующих сериях.

## Стек

- **Flutter** 3.47+ / **Dart** 3.13+
- **Material 3** (UI)
- **`dio`** — HTTP-клиент для API (добавим в bundle-2)
- **`flutter_secure_storage`** — хранение JWT (bundle-2)
- **`provider`** — управление состоянием (bundle-2)
- **`mobile_scanner`** — сканирование QR (bundle-4)

## Целевые устройства

- Android-планшеты (основное).
- Реальные устройства через USB-отладку.
- Эмулятор Pixel Tablet.
