# WMS Geology

Система управления складским хранением геологических материалов.

## Что это

Единая база данных + веб-приложение (Windows/браузер) + Android-приложение
для планшетов. Управляет адресным хранением проб, наряд-заданиями,
QR-идентификацией тары и ячеек, инвентаризацией и отчётностью.

## Для кого

- **Менеджеры** — создание наряд-заказов, аналитика, отчёты.
- **Рабочие (кладовщики)** — приёмка, выдача, перемещения, инвентаризация.
- **Администраторы** — управление пользователями, топологией, БД.

## Стек

- **БД:** PostgreSQL 16+
- **Backend:** Python 3.12 + Django + DRF
- **Mobile:** Flutter (Android-планшет)
- **Web:** React + TypeScript

Все компоненты — под разрешительными лицензиями (MIT / Apache 2.0 /
BSD). Проект готов к коммерческому использованию.
