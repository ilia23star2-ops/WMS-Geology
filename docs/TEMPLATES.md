# TEMPLATES.md — шаблоны проектных доков

> Шаблоны для создания доков конкретного проекта.
> Копируешь нужный шаблон → заполняешь → кладёшь в `docs/` проекта
> под своим именем.
>
> Базовые четыре — почти всегда. Дополнительные три — по
> надобности.

---

3. Шаблон: Сценарии
Когда нужен. Есть сложное поведение — UI, взаимодействие
шагов, жизненный цикл. Сценарии помогают сверять поведение
с реализацией.

Имя файла в проекте: SCENARIOS.md.

markdown
# SCENARIOS.md — сценарии работы

> Пошаговые сценарии. Разбираются по блокам.

- **Р** — рабочий
- `"..."` — произносимая фраза
- `{...}` — действие
- `[...]` — текст в интерфейсе
