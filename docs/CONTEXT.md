## Известные грабли

### Домен

- Проба **не уникальна** по номеру. Уникальна по `sample_id`.
- `SampleParts` **не нужна** — проба и есть единица хранения.
- Одна тара = **один** тип исследования.
- Разделение Н/З — **вне WMS**, мы фиксируем результат.
- `WorkOrders.linked_order_id` — связь INCOMING ↔ CODED.
- Проба связана с Н/З через `SampleWorkOrders` (M:N).

### Документация

- В проектной фазе заход = 1 документ, тесты не пишутся.
- `RULES.md` и `TEMPLATES.md` — копируются **как есть**, не правятся.
- Всё специфичное для проекта — в `PROJECT.md`.
- Файлы доков выдаются **единым блоком** для удобства копирования.

### Инструменты

- Git — только терминал. Никаких IDE-панелей.
- VS Code — основной. Android Studio — только мобильное.
- Терминал VS Code — **Git Bash** (не PowerShell).
- SSH работает через `ssh.github.com:443` (см. `~/.ssh/config`).
