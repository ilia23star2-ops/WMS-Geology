### 1.34. 2026-10-07 — JWT для API, сессии только для Django Admin

**Решение:**
- **Аутентификация API** — JWT (`djangorestframework-simplejwt`).
  Эндпоинты: `/api/v1/auth/login/`, `/refresh/`, `/logout/`, `/me/`.
- **Session-аутентификация** остаётся как fallback для Django Admin.
- Порядок `DEFAULT_AUTHENTICATION_CLASSES`: сначала JWT, потом Session.
- **OpenAPI-схема** — `drf-spectacular`, доступна на `/api/schema/`
  (YAML) и `/api/docs/` (Swagger UI).

**Причина:**
- Мобильное приложение и SPA не могут работать с CSRF-cookies
  и сессиями так же удобно, как с токенами.
- JWT — стандарт для мобильных и SPA-клиентов.
- Session — нужен для Django Admin, не ломать существующее.
- `drf-spectacular` — самый современный генератор OpenAPI 3 для DRF;
  contract-тесты гарантируют, что схема соответствует коду.

**Конфигурация:**
- `ACCESS_TOKEN_LIFETIME` — 60 минут (из `.env`).
- `REFRESH_TOKEN_LIFETIME` — 7 дней.
- `ROTATE_REFRESH_TOKENS=False`, `BLACKLIST_AFTER_ROTATION=True`.
- Logout использует blacklist (`rest_framework_simplejwt.token_blacklist`).

**Где:** `backend/wms_geology/settings.py`, `backend/apps/users/`,
`backend/tests/test_openapi.py`.
**Статус:** ✅ действует.

## 2. Что не делаем и почему

- **Не используем `SampleParts`.**
- **Не храним две колонки для Н/З.**
- **Не заставляем лаборатории использовать наш формат.**
- **Не переклеиваем старые этикетки.**
- **Не используем закрытые лицензии в ядре.**
- **Не создаём кастомную модель User.**
- **Не используем Django fixtures для seeds.**
- **Не запускаем Django-команды через кнопку «Run» в VS Code.**
- **Не клеим QR на поддоны и пробы в MVP.**
- **Не удаляем пробы физически.**
- **Не блокируем размещение при превышении вместимости.**
- **Не реализуем bin packing и учёт веса в MVP.**
- **Не реализуем логику керна в MVP.**
- **Не патчим миграции v1 через `0002`.**
- **Не требуем не-NULL сразу для pallet/container в move item.**
- **Не используем session-based auth для API.**
- **Не пишем OpenAPI-схему вручную** — генерируется через drf-spectacular.

## 4. Что НЕ значат эти термины

- «**Часть пробы**» — не используется.
- «**Ячейка**» — не слот на 3 поддона. **1 поддон**.
- «**Поддон**» — «тихий» объект, без QR и pallet_code.
- «**Наряд-заказ**» — входящий и зашифрованный — разные строки.
- «**Проба**» — не уникальна по номеру.
- «**User**» — Django-овский.
- «**Pallet.position_in_cell**» — нет такого.
- «**Cell.max_pallets**» — нет. Вместимость у поддона.
- «**Auth**» в API — JWT, не сессии (сессии только для Admin).
