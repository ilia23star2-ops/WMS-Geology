### 1.20. 2026-10-07 — Топология склада: 4 яруса A–D, 1 поддон в ячейке

**Решение:**
Комната
└── Стеллаж
└── Секция (пролёт)
├── Ярус A (level 1, нижний)
│ ├── Ячейка 1 → 1 поддон → N тар → M проб
│ ├── Ячейка 2 → 1 поддон → N тар
│ └── Ячейка 3 → 1 поддон → N тар
├── Ярус B (level 2)
├── Ярус C (level 3)
└── Ярус D (level 4, верхний)

text

- Ярусов — **ровно 4** (A, B, C, D), маркируются буквами снизу вверх.
- Ячеек на ярусе — **3**.
- В ячейке — **ровно 1 поддон**.

**Причина:** соответствует физической планировке склада; буквенная маркировка совпадает с маркировкой на стеллажах.

**Где:** `backend/apps/storage/models.py`, `docs/DATABASE.md`.
**Статус:** ✅ действует.

### 1.21. 2026-10-07 — `Pallet` — «тихий» объект (Вариант A)

**Решение:** модель `Pallet` **остаётся**, но:
- Нет QR-кода (физически на поддоне его нет).
- Нет пользовательского `pallet_code`.
- Нет `position_in_cell` (1 ячейка = 1 поддон).
- `cell` → **OneToOneField**.
- Есть `pallet_type` и `capacity_override`.

**Причина:** «информация о хранении живёт в ячейке», но поддон мобилен — при перемещении поддона все тары «уезжают» вместе (FK тары на поддон не меняется).

**Где:** `backend/apps/storage/models.py`.
**Статус:** ✅ действует.

### 1.22. 2026-10-07 — QR-стратегия: только секция, ячейка, тара

**Решение:**

| Объект | QR |
|---|---|
| Комната | ❌ |
| Стеллаж | ❌ |
| **Секция (пролёт)** | ✅ Обязателен |
| **Ячейка** | ✅ Обязателен |
| ~~Поддон~~ | ❌ |
| **Тара** | ✅ Обязателен |
| Проба | ❌ |

**Payload:**
- Секция: `WMSG:SECTION:<id>`
- Ячейка: `WMSG:CELL:<id>`
- Тара: `WMSG:CONTAINER:<id>`

**Причина:** на поддонах физически нет QR; QR на секции даёт виртуальный вид всех ярусов A–D без лазания наверх.

**Где:** `docs/DATABASE.md`, `docs/SCENARIOS.md`.
**Статус:** ✅ действует.

### 1.30. 2026-10-07 — Помощник по сортировке: 4 функции в MVP

**Решение:** в MVP:
1. Рекомендация ячейки для готового поддона.

### 1.32. 2026-10-07 — CHECK `move_item_pallet_xor_container` разрешает оба NULL

**Решение:** для `MoveOperationItem` CHECK разрешает:
- `pallet` задан, `container` = NULL;
- `pallet` = NULL, `container` задан;
- **оба NULL**.

**Запрещено:** оба заданы одновременно.

**Причина:** при удалении поддона Django обнуляет `pallet_id` (SET_NULL); если CHECK требует «ровно одно не NULL», строка ломается. Оба NULL = сохраняем историю.

**Где:** `backend/apps/movements/models.py`.
**Статус:** ✅ действует.

### 1.33. 2026-10-07 — Docker Compose для PostgreSQL на домашнем ПК

**Решение:** на домашнем ПК PostgreSQL через **Docker Compose**:
- `docker-compose.yml` в корне проекта;
- образ `postgres:16`, контейнер `wms-geology-postgres`;
- volume `postgres_data`.

**Причина:** полноценный PostgreSQL без установки; файл в репозитории → воспроизводимо; тот же образ, что в CI.

**Разные окружения:**
- Рабочий ПК — портативный PostgreSQL (1.14).
- Домашний ПК — Docker Compose.
- Параметры подключения одинаковые.

**Где:** `docker-compose.yml`, `backend/.env`.
**Статус:** ✅ действует.

## 2. Что не делаем и почему

- **Не используем `SampleParts`.**
- **Не храним две колонки для Н/З.**
- **Не заставляем лаборатории использовать наш формат.**
- **Не переклеиваем старые этикетки.**
- **Не используем закрытые лицензии в ядре.**
- **Не создаём кастомную модель User.**
- **Не используем Django fixtures для seeds.**
- **Не запускаем Django-команды через кнопку «Run» в VS Code.**
- **Не клеим QR на поддоны и пробы в MVP.**
- **Не удаляем пробы физически.**
- **Не блокируем размещение при превышении вместимости.**
- **Не реализуем bin packing и учёт веса в MVP.**
- **Не реализуем логику керна в MVP.**
- **Не патчим миграции v1 через `0002`** — пересоздаём (1.31).
- **Не требуем не-NULL сразу для pallet/container** (1.32).

## 4. Что НЕ значат эти термины

- «**Часть пробы**» — не используется.
- «**Ячейка**» — не слот на 3 поддона. **1 поддон**.
- «**Поддон**» — «тихий» объект, без QR и pallet_code.
- «**Наряд-заказ**» — входящий и зашифрованный — разные строки.
- «**Проба**» — не уникальна по номеру.
- «**User**» — Django-овский.
- «**Pallet.position_in_cell**» — нет такого.
- «**Cell.max_pallets**» — нет. Вместимость у поддона.
