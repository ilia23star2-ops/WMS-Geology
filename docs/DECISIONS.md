### 1.31. 2026-10-07 — Миграции v1 пересозданы, а не патч `0002`

**Решение:** при переходе от топологии v1 к v2 миграции приложений
`storage`, `samples`, `inventory` **пересозданы**:
- откат `migrate <app> zero`;
- удаление `0001_initial.py`;
- генерация нового `0001_initial.py` под v2.

**Причина:**
- Топология v1 — черновик, признанный ошибочным (см. 1.20).
- Прод не выкатывали, данных нет.
- `makemigrations` при FK→OneToOne и массовых изменениях может
  создать запутанную миграцию; пересоздать чище.
- Git-история коммитов серии 1.0 сохранена (миграции — не источник
  правды, источник — `DATABASE.md`).

**Где:** `backend/apps/*/migrations/0001_initial.py`.
**Статус:** ✅ действует.

### 1.32. 2026-10-07 — CHECK `move_item_pallet_xor_container` разрешает оба NULL

**Решение:** для `MoveOperationItem` CHECK разрешает:
- `pallet` задан, `container` = NULL;
- `pallet` = NULL, `container` задан;
- **`pallet` = NULL, `container` = NULL**.

**Запрещено:** оба заданы одновременно.

**Причина:**
- При удалении поддона Django обнуляет `pallet_id` (SET_NULL).
- Если CHECK требует «ровно одно не NULL», строка ломается.
- Разрешение обоих NULL = сохраняем историю операции, даже если
  объект удалён.
- То же решение уже используется у `Pallet` (1.18).

**Где:** `backend/apps/movements/models.py`.
**Статус:** ✅ действует.

### 1.33. 2026-10-07 — Docker Compose для PostgreSQL на домашнем ПК

**Решение:** на домашнем ПК (админ-права) PostgreSQL поднимается
через **Docker Compose**:
- файл `docker-compose.yml` в корне проекта;
- образ `postgres:16`, контейнер `wms-geology-postgres`;
- volume `postgres_data` для персистентности.

**Причина:**
- Полноценный PostgreSQL без установки службы в систему.
- `docker-compose.yml` в репозитории → воспроизводимо на любой машине
  с Docker.
- Тот же образ, что в `.github/workflows/ci.yml` → консистентность.
- Легко снести: `docker compose down -v`.

**Разные окружения:**
- **Рабочий ПК:** портативный PostgreSQL (нет админ-прав, см. 1.14).
- **Домашний ПК:** Docker Compose (есть админ-права).
- Параметры подключения одинаковые (`wms_user` / `wms_password` /
  `wms_geology` / `localhost:5432`).

**Где:** `docker-compose.yml`, `backend/.env`.
**Статус:** ✅ действует.

## 2. Что не делаем и почему

- **Не используем `SampleParts`.** Разделение — вне WMS.
- **Не храним две колонки для Н/З.** Не масштабируется.
- **Не заставляем лаборатории использовать наш формат.**
- **Не переклеиваем старые этикетки.**
- **Не используем закрытые лицензии в ядре.**
- **Не создаём кастомную модель User.**
- **Не используем Django fixtures для seeds.**
- **Не запускаем Django-команды через кнопку «Run» в VS Code.**
- **Не клеим QR на поддоны и пробы в MVP.**
- **Не удаляем пробы физически.**
- **Не блокируем размещение при превышении вместимости** (предупреждение).
- **Не реализуем bin packing и учёт веса в MVP.**
- **Не реализуем логику керна в MVP.**
- **Не патчим миграции v1 через `0002`** — пересоздаём (1.31).
- **Не требуем не-NULL сразу для pallet/container в move item** (1.32).

## 3. Глоссарий

### Данные

| Термин | Что значит |
|---|---|
| **Проба (Sample)** | Физическая единица хранения. |
| **Наряд-заказ (Н/З)** | Группа проб. `INCOMING` / `CODED`. |
| **Тип исследования** | Ключевой критерий. |
| **Тара (Container)** | Физический контейнер. |
| **Тип тары (ContainerType)** | Справочник: коробка, ящик, кернобокс. |
| **Поддон (Pallet)** | «Тихий» объект. OneToOne с ячейкой. |
| **Ячейка (Cell)** | Место на ярусе. 1 поддон. |
| **Секция** | Пролёт стеллажа с 4 ярусами A–D. |
| **Адрес** | Комната / Стеллаж / Секция / Ярус / Ячейка. |
| **Скважина (Well)** | Источник пробы. |

## 4. Что НЕ значат эти термины

- «**Часть пробы**» — не используется.
- «**Ячейка**» — не слот на 3 поддона. Слот на **1 поддон**.
- «**Поддон**» — «тихий» объект, без QR и pallet_code.
- «**Наряд-заказ**» — входящий и зашифрованный — разные строки.
- «**Проба**» — не уникальна по номеру.
- «**User**» — Django-овский.
- «**Pallet.position_in_cell**» — нет такого. 1 ячейка = 1 поддон.
- «**Cell.max_pallets**» — нет. Вместимость у поддона.
