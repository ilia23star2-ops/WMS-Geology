## 1. Дизайн-система

### Цвета

| Роль | Значение | Где |
|---|---|---|
| **Primary** | `#1E3A5F` (тёмно-синий) | Заголовки, акценты, кнопки действий |
| **Secondary** | `#4A6572` | Второстепенные элементы |
| **Success** | `#2E7D32` (зелёный) | Валидные состояния, «всё сходится» |
| **Warning** | `#F57C00` (оранжевый) | Предупреждения |
| **Error** | `#C62828` (красный) | Ошибки, расхождения |
| **Info** | `#0288D1` | Подсказки |
| **Background** | `#F5F5F5` | Фон страниц |
| **Surface** | `#FFFFFF` | Карточки |
| **Text Primary** | `#212121` | Основной текст |
| **Text Secondary** | `#757575` | Подписи |

**Material 3** — базовая тема. Генерация палитры от `seedColor = #1E3A5F`.

### Шрифты

- **Основной:** Inter (или Roboto — системный Android).
- **Моно:** JetBrains Mono — для номеров проб, ШК.

### Размеры

| Уровень | Размер | Применение |
|---|---|---|
| H1 | 28 pt | Заголовки страниц |
| H2 | 22 pt | Заголовки разделов |
| H3 | 18 pt | Заголовки карточек |
| Body | 14 pt | Основной текст |
| Caption | 12 pt | Подписи, хинты |
| Mono | 13 pt | Номера проб, коды |

### Отступы

Базовый шаг — **8 px**. Отступы: `8 / 16 / 24 / 32`.

### Компоненты

- **Кнопки:** Filled (главное действие), Outlined (второстепенное), Text (ссылки).
- **Поля ввода:** Outlined, с подписью сверху.
- **Чекбоксы:** квадратные, 20×20.
- **Карточки:** скругление 8 px, тень мягкая.
- **Диалоги:** модальные, с затемнением фона.

┌─ НОВАЯ ПАРТИЯ ───────────────────────────────────────┐
│ │
│ ☐ Входящий Н/З │
│ │
│ Текущий Н/З * │

│ │
│ ┌─── если ☑ Входящий Н/З ─────────────────────┐ │
│ │ Входящий Н/З * │ │
│ │ [02-Тест001_____________________________] ▾ │ │
│ │ ℹ Автоматически связано с TST0001. │ │
│ │ Если нет — сохранится и привяжется. │ │
│ └───────────────────────────────────────────────┘ │
│ │
│ Тип исследования * │
│ [ШЛ_______________________________________] ▾ │
│ ↳ [+ Добавить новый тип] │
│ │
│ Кол-во тары * │
│ [5___] │
│ │
│ ───────────────────────────────────────────── │
│ Автоопределение: │
│ Участок: ✓ Тестовый │

│ ───────────────────────────────────────────── │
│ │
│ [Создать партию] │
└───────────────────────────────────────────────────────┘

text

**Поведение:**
- Чекбокс «Входящий Н/З» → раскрывает поле.
- Если у текущего Н/З есть `linked_order` → поле входящего заполняется автоматически.
- Тип — справочник + кнопка «Добавить новый».
- Участок/лаборатория — read-only, авто.

## 4. Макет 3. Заполнение тары
┌─ ТАРА 1 (T-001) ──────────────────────────────────────┐
│ │
│ ┌─ ШАПКА (авто) ──────────────────────────────┐ │
│ │ Участок: Тестовый │ │
│ │ Наряд: 02-Тест001 (вх) / TST0001 │ │
│ │ Тип: ШЛ │ │
│ │ Номер тары: [T-001____________________] │ │
│ └──────────────────────────────────────────────┘ │
│ │
│ Кол-во проб в таре * │
│ [31___] │
│ │
│ ── СКВАЖИНЫ ── │
│ │
│ ┌────────────────────────────────────────────────┐ │
│ │ [TAA-A34076001-031_______________________] [✏] │ │
│ └────────────────────────────────────────────────┘ │
│ Скв 1 · 31 проба · ✓ сходится │
│ │
│ [+ Добавить скважину] │
│ │
│ ──────────────────────────────────────────────── │
│ Итого по таре: 31 / 31 ✓ │
│ ──────────────────────────────────────────────── │
│ │
│ [💬 Комментарий] [👁 Предпросмотр] [Сохранить] │
└────────────────────────────────────────────────────────┘

text

**Поведение:**
- Строка скважины: полный номер с диапазоном **целиком**: `TAA-A34076001-031`.
- По мере ввода — **подсказки (ghost text):**
  - Знакомые префиксы.
  - Похожие скважины.
  - Совпадения из других тар.
- `[✏]` → открывает Макет 4.
- `[+ Добавить скважину]` — новая строка.
- `[Сохранить]` активна только при `Итого = Кол-во проб`.

**Фон строки:**
- 🟢 Зелёный — сходится.
- 🟡 Жёлтый — не всё заполнено.
- 🔴 Красный — расхождение.

┌─ РЕДАКТИРОВАНИЕ СКВАЖИНЫ ─────────────────────────────┐
│ │
│ ☐ Показать всё (развернуть на весь экран) │
│ │
│ ── РАЗБОР НОМЕРА ── │
│ Скважина: [124_______________________] │
│ Префикс: [TAA-A______________________] │
│ Порядковый номер: [031_______________________] │
│ │
│ ℹ Эти поля также редактируются в основной строке. │
│ │
│ ── ОТСУТСТВУЮТ (физически нет и в списках) ── │
│ [2, 4-7_____________________________] │
│ ℹ Примеры: «2, 4-7, 15» │
│ │
│ ── ВЫБРАНЫ (нет физически, но есть в списках) ── │
│ [1, 8-9_____________________________] │
│ │
│ ── ИТОГО ── │
│ Диапазон: 31 │
│ Отсутствуют: -5 │
│ Выбраны: -3 │
│ Итого: 23 │
│ │
│ [Применить] [Отмена] │
└────────────────────────────────────────────────────────┘

text

**Термины по-русски:**
- Sequence → **Порядковый номер**.
- Prefix → **Префикс**.
- Selected → **Выбраны**.
- Missing → **Отсутствуют**.

## 7. Макет 6. Формат этикетки (20×12 см)
┌─────────────────────────────────────────────────┐
│ ШАПКА ┌───────────┐ │
│ Участок: Тестовый │ │ │
│ Наряд: 02-Тест001 (вх) │ │ │
│ TST0001 │ [QR] │ │
│ Тип: ШЛ │ │ │
│ Тара: T-001 │ #12345 │ │
│ └───────────┘ │
├─────────────────────────────────────────────────┤
│ СПИСОК ПРОБ │
│ ┌───┬────────────────────────┬─────────────┐ │
│ │ ☐ │ 1. TAA-A34076001-001 │ ☐ 1. ... │ │
│ │ ☐ │ 2. TAA-A34076001-002 │ ☐ 2. ... │ │
│ │ ☐ │ 3. TAA-A34076001-003 │ ☐ 3. ... │ │
│ │ ☐ │ 4. TAA-A34076001-004 │ ☐ 4. ... │ │
│ │ ☐ │ 5. TAA-A34076001-005 │ ☐ 5. ... │ │
│ │ ☐ │ 6. TAA-A34076001-006 │ ☐ 6. ... │ │
│ └───┴────────────────────────┴─────────────┘ │
└─────────────────────────────────────────────────┘

text

**Раскладка:**
- Шапка — верхний левый угол.
- QR + ID — верхний правый угол.
- Список проб — 2 колонки.
- Чекбокс слева от каждой пробы — для физической отметки «выбрано».

**Авто-масштаб:**
- ≤ 15 проб → 1 колонка, обычный шрифт.
- 16–60 проб → 2 колонки, авто-размер шрифта.
- > 60 проб → разбить на несколько этикеток (`1/2`, `2/2`).
- Порог уточняется при тестовой печати.

**Пустая тара** — этикетку не печатаем. Предупреждение: «Введите пробы».

## 10. Адаптация под разные экраны

### Мобильное (планшет, ~10")

- Макеты 1-5 — на полный экран.
- Свайп слева → боковое меню.
- Свайп справа → быстрые действия.

### Веб (ПК, ≥ 1280 px)

- Макеты в модальных окнах или отдельных страницах.
- Двухколоночная вёрстка для карточек.
- Sidebar постоянный (сворачиваемый).

### Общее

- Единый Material 3.
- Единый шрифт.
- Единые цвета и отступы.

## 11. Открытые вопросы

1. **Порог 1/2 колонки этикетки** — эмпирически при тестовой печати.
2. **Показ комментария к таре в предпросмотре этикетки** — нужен или нет?
3. **Цветные метки для статусов проб** (`PRESENT / SELECTED / MISSING`) — нужны ли в форме, или достаточно текстовых полей?
4. **Звук при сканировании QR** — включать или нет?
5. **Тёмная тема** — нужна ли на старте?
