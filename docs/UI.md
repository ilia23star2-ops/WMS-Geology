# UI.md — дизайн-система и макеты

> Единый стиль для веб-приложения и мобильного клиента.

**Дата:** 2026-10-08

---

## 1. Дизайн-система

### Цвета

| Роль | Значение | Где |
|---|---|---|
| **Primary** | `#1E3A5F` (тёмно-синий) | Заголовки, кнопки действий |
| **Secondary** | `#4A6572` | Второстепенные элементы |
| **Success** | `#2E7D32` (зелёный) | Валидные состояния |
| **Warning** | `#F57C00` (оранжевый) | Предупреждения |
| **Error** | `#C62828` (красный) | Ошибки, расхождения |
| **Info** | `#0288D1` | Подсказки |
| **Background** | `#F5F5F5` | Фон страниц |
| **Surface** | `#FFFFFF` | Карточки |
| **Text Primary** | `#212121` | Основной текст |
| **Text Secondary** | `#757575` | Подписи |

Material 3, генерация палитры от `seedColor = #1E3A5F`.

### Шрифты

- **Основной:** Inter (или Roboto).
- **Моно:** JetBrains Mono — для номеров проб, ШК.

### Размеры

| Уровень | Размер |
|---|---|
| H1 | 28 pt |
| H2 | 22 pt |
| H3 | 18 pt |
| Body | 14 pt |
| Caption | 12 pt |
| Mono | 13 pt |

### Отступы

Шаг 8 px. Значения: `8 / 16 / 24 / 32`.

## 18. Адаптация

### Мобильное (планшет, ~10")

- Макеты 1-5 — на полный экран.
- Свайп слева → боковое меню.

### Веб (ПК, ≥ 1280 px)

- Модальные окна или отдельные страницы.
- Sidebar постоянный.

### Общее

- Единый Material 3.
- Единый шрифт.
- Единые цвета и отступы.

## 19. Открытые вопросы

1. **Порог 1/2 колонки этикетки** — эмпирически при тестовой печати.
2. **Показ комментария к таре в предпросмотре этикетки** — нужен?
3. **Цветные метки статусов проб** (`PRESENT / SELECTED / MISSING`) — нужны?
4. **Звук при сканировании QR** — включать?
5. **Тёмная тема** — нужна на старте?
6. **Шаблоны сопроводительного документа** — фиксированный или настраиваемый?
7. **Чек-лист для машины** — обязательный или опциональный?
