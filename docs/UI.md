## 1. Дизайн-система

### Цвета

| Роль | Значение | Где |
|---|---|---|
| **Primary** | `#1E3A5F` (тёмно-синий) | Заголовки, кнопки действий |
| **Secondary** | `#4A6572` | Второстепенные элементы |
| **Success** | `#2E7D32` (зелёный) | Валидные состояния |
| **Warning** | `#F57C00` (оранжевый) | Предупреждения |
| **Error** | `#C62828` (красный) | Ошибки, расхождения |
| **Info** | `#0288D1` | Подсказки |
| **Background** | `#F5F5F5` | Фон страниц |
| **Surface** | `#FFFFFF` | Карточки |
| **Text Primary** | `#212121` | Основной текст |
| **Text Secondary** | `#757575` | Подписи |

**Material 3, генерация палитры от `seedColor = #1E3A5F`.**
В MUI — через `createTheme({ palette: { primary: { main: "#1E3A5F" } } })`.

### Шрифты

- **Основной:** Inter (fallback Roboto).
- **Моно:** JetBrains Mono — для номеров проб, ШК.

### Размеры

| Уровень | Размер |
|---|---|
| H1 | 28 pt |
| H2 | 22 pt |
| H3 | 18 pt |
| Body | 14 pt |
| Caption | 12 pt |
| Mono | 13 pt |

В MUI — `typography.h1` / `.h2` / `.h3` / `.body1` / `.caption`.

### Отступы

Шаг 8 px. В MUI — `theme.spacing(1)` = 8 px.
Значения: `8 / 16 / 24 / 32` (`spacing(1..4)`).

### UI-библиотека

**MUI (Material UI) v5+**. Почему:
- Material 3 — целевой дизайн (см. §Цвета).
- Готовые компоненты: `DataGrid`, `TextField`, `Button`, `Drawer`.
- Тёмная тема «из коробки».
- Хорошо документирован.

### Статусы тары — цвета чипов

| Статус | Метка | Цвет |
|---|---|---|
| `PENDING_FILLING` | Ожидает заполнения | `warning` |
| `PENDING_PLACEMENT` | Ожидает размещения | `warning` |
| `ACTIVE` | Размещена | `success` |
| `IN_TRANSIT` | В пути | `info` |
| `ISSUED` | Выдана | `default` |

### Статусы строки приёмки — цвета чипов

| Статус | Метка | Цвет |
|---|---|---|
| `EXPECTED` | Ожидается | `default` |
| `MATCHED` | Совпадает | `success` |
| `DISCREPANCY` | Расхождение | `warning` |
| `MISSING` | Отсутствует | `error` |
| `EXTRA` | Лишняя | `warning` |
| `PENDING_DECRYPTION` | Ожидает расшифровки | `default` |

## 7. Макет 6. Этикетка (модель 4d, реализовано)

**Спецификация — DECISIONS.md §1.55.**

**Что реализовано:**
- Формат: **адаптивный** (сетка ширин × сетка высот).
- Ширина: `[110, 130, 150, 180, 210]` мм.
- Высота: `[37, 49, 74, 99, 148]` мм (делители A4).
- Шапка 28 мм: QR 25×25 в правом верхнем углу, 4 строки слева
  (`Уч` / `Н/З` / `Исл` / `№`).
- Рабочая область: таблица `п/п | Образец` с чекбоксами.
- QR-сетка (`QR_ONLY`): 8 × 11 = 88 QR 25×25 на A4.
- QR-payload — внутренний `id` тары (`WMSG:CONTAINER:<id>`),
  не номер.

Актуальные макеты — в `label_service.py` (реализация).

## 24. Адаптация

### Мобильное (планшет, ~10")

- Макеты 1-5 — на полный экран.
- Свайп слева → боковое меню.
- **Flutter** — Material 3 из коробки.

### Веб (ПК, ≥ 1280 px)

- **MUI**: `Drawer` (sidebar), `AppBar`, `Dialog` (модалки).
- Sidebar постоянный.
- **MUI DataGrid** — для реестров (containers, samples, справочники).
- **Топология** — двухпанельный вид: дерево (левая) + DataGrid (правая).

### Общее

- Единый Material 3.
- Единый шрифт (Inter / Roboto).
- Единые цвета и отступы.
