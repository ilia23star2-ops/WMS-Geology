> Единый стиль для веб-приложения и мобильного клиента.

**Дата:** 2026-10-08
**Дата обновления:** 2026-10-10
**Реализация:** MUI (Material UI) — веб, Flutter Material 3 — mobile.

---

## 1. Дизайн-система

### Цвета

| Роль | Значение | Где |
|---|---|---|
| **Primary** | `#1E3A5F` (тёмно-синий) | Заголовки, кнопки действий |
| **Secondary** | `#4A6572` | Второстепенные элементы |
| **Success** | `#2E7D32` (зелёный) | Валидные состояния |
| **Warning** | `#F57C00` (оранжевый) | Предупреждения |
| **Error** | `#C62828` (красный) | Ошибки, расхождения |
| **Info** | `#0288D1` | Подсказки |
| **Background** | `#F5F5F5` | Фон страниц |
| **Surface** | `#FFFFFF` | Карточки |
| **Text Primary** | `#212121` | Основной текст |
| **Text Secondary** | `#757575` | Подписи |

**Material 3, генерация палитры от `seedColor = #1E3A5F`.**
В MUI — через `createTheme({ palette: { primary: { main: "#1E3A5F" } } })`.

### Шрифты

- **Основной:** Inter (fallback Roboto).
- **Моно:** JetBrains Mono — для номеров проб, ШК.

### Размеры

| Уровень | Размер |
|---|---|
| H1 | 28 pt |
| H2 | 22 pt |
| H3 | 18 pt |
| Body | 14 pt |
| Caption | 12 pt |
| Mono | 13 pt |

В MUI — `typography.h1` / `.h2` / `.h3` / `.body1` / `.caption`.

### Отступы

Шаг 8 px. В MUI — `theme.spacing(1)` = 8 px.
Значения: `8 / 16 / 24 / 32` (`spacing(1..4)`).

### UI-библиотека

**MUI (Material UI) v5+**. Почему:
- Material 3 — целевой дизайн (см. §Цвета).
- Готовые компоненты: `DataGrid`, `TextField`, `Button`, `Drawer`.
- Тёмная тема «из коробки».
- Хорошо документирован.

## 7. Макет 6. Этикетка (заменено 1.55)

**Статус:** ⚠ Устарело. Заменено на **модель 4d** — см.
`DECISIONS.md` §1.55 и `DATABASE.md` §PrintBatches.

**Что изменилось:**
- Формат: **адаптивный** (сетка ширин × сетка высот).
- Ширина: `[110, 130, 150, 180, 210]` мм.
- Высота: `[37, 49, 74, 99, 148]` мм (делители A4).
- Шапка 28 мм: QR 25×25 в правом верхнем углу, 4 строки слева
  (`Уч` / `Н/З` / `Исл` / `№`).
- Рабочая область: таблица `п/п | Образец` с чекбоксами.
- QR-сетка (`QR_ONLY`): 8 × 11 = 88 QR 25×25 на A4.

Актуальные макеты — в `label_service.py` (реализация) и
`DECISIONS.md` §1.55 (спецификация).
