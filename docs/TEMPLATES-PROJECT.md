> Дополняют `TEMPLATES.md` (копию из `ai-development-template`).
> `TEMPLATES.md` **не правится в проекте** — все проектные
> дополнения идут сюда.

---

## Дополнение 1: Шаблон `API.md`

**Когда нужен.** Есть собственный API, который потребляют клиенты
(мобильное приложение, веб, внешние сервисы).

**Имя файла в проекте:** `API.md`.

**Структура:**
1. **Заголовок.** Базовый URL, формат данных, аутентификация,
   пагинация.
2. **Аутентификация.** Таблица эндпоинтов (метод, путь, действие).
3. **По ресурсам.** Для каждого ресурса — таблица эндпоинтов +
   примеры JSON запроса/ответа + фильтры.
4. **Служебные эндпоинты.** Сканирование, поиск, отчёты.
5. **Формат ошибок.** Единый для всех 4xx/5xx.
6. **Открытые вопросы.** Что ещё не решено.

**Пример реализации.** См. `docs/API.md` в этом проекте.

**Ключевые правила:**
- Один ресурс — одна таблица эндпоинтов.
- Для каждого `GET` — список фильтров.
- Для `POST` / `PATCH` — пример тела запроса.
- Формат ошибок — единый, без вариаций.
- Версия API — в URL (`/api/v1/`).

## Дополнение 2: Шаблон `TEMPLATES-PROJECT.md` (этот файл)

**Когда нужен.** Всегда, если есть проектные дополнения к базовым
шаблонам.

**Правило.** Базовые шаблоны живут в `TEMPLATES.md`. Проектные
дополнения — здесь. Это позволяет обновлять базовый шаблон, не
теряя проектные наработки.

**Структура файла:**
- Заголовок и правило разделения.
- По одному разделу на каждое дополнение.
- Каждый раздел: «когда нужен», «имя файла», «структура»,
  «пример», «правила».
