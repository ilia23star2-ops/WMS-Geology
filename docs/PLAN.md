## Стратегия

> **Web — основной клиент. Mobile — по требованию.**

1. **Web-фичи — первый приоритет.** Всё, что можно проверить в браузере,
   делается на web.
2. **Mobile — по требованию.** Если web-фича требует проверки на
   устройстве (сканирование QR, камера, физические манипуляции у машины) —
   web ставится на паузу, mobile доводится до минимума, проверяется,
   возвращаемся к web.
3. **Роли и права — после.** Пока всё тестируется всеми.
4. **`Receipt`** — только для Excel и акта приёмки. Оцифровка и ручной
   ввод идут через `Container` + `Sample` напрямую.

## Требует обсуждения (серия `2.x-lifecycle`)

> Открытые вопросы по доменной модели. Собраны при работе над web.
> **Обсуждать с заказчиком до старта серии.** Ответы записать в
> `DECISIONS.md`.

**1. Статусы тары.**
- `ACTIVE` («Размещена») — лежит на месте.
- `PENDING_PLACEMENT` («Ожидает размещения») — без места.
- `IN_TRANSIT` («В пути») — что значит? Едет к нам / от нас?
- `ISSUED` («Выдана» / «У лаборатории») — куда? Навсегда?
- Нужен ли `MOVING` (внутреннее перемещение)?

**2. Статусы пробы.**
- `IN_STORAGE` («В хранении»), `IN_TRANSIT` («В пути»),
  `ISSUED` («Выдана»), `CONSUMED` («Израсходована»),
  `DISPOSED` («Утилизирована»), `PENDING_DECRYPTION`.
- Что значит каждый? Семантика размыта.

**3. Отправка в лабораторию.**
- Тара едет с пробами или пробы перекладываются?
- Тара после отправки — «выбыла навсегда» или «у лаборатории»?

**4. Возврат.**
- Возврат = новый объект (Container / Sample) или обновление
  старого?
- Кто решает — кладовщик / автоматика?
- Связь отправка ↔ возврат (`Receipt.shipment_id`) — используем?

**5. Наряд-заказ.**
- Что с Н/З после отправки всех проб? Закрывается / остаётся /
  архив?

**6. Шифрование номеров.**
- Проба приходит шифрованная / нешифрованная.
- Расшифровка от ЛИМС.
- Где хранить соответствие (`Sample.legacy_data` / отдельно)?

**7. Преемственность.**
- Нужна ли связь «новый Container = перерождение старого»
  (`parent_container_id`)?
- То же для `Sample`.

**8. Кто меняет статусы.**
- Кладовщик вручную / система автоматически / менеджер?

**9. Приёмка ↔ отправка.**
- `Shipment.status = RECEIVED` — кто ставит?
- Частичный возврат (`PARTIALLY_RECEIVED`) — реальный сценарий?
