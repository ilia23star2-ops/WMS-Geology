
39. Якоря для точечных правок — короткие однострочные.
VS Code автоформатирует вставленный код и переносит длинные строки,
поэтому многострочный якорь из вывода ИИ не совпадёт с файлом на диске.
- Якорь — короткий фрагмент одной строки: сигнатура, вызов, import.
- Маркер проверяет определение, а не вызов: иначе замена вызова даёт ложное true.
- Кавычки Dart внутри node -e собирать через String.fromCharCode(39).
- Regex с кавычками не использовать: считать через split/includes.
Источник: sync-fix-1 .. conflict-samples-12, четыре промаха по якорям.
